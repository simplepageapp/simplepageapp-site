AMV Rift Publisher

Privacy Policy

Who uses it

AMV Rift Publisher is a private tool used only by the owner of the AMV Rift YouTube channel to manage that channel. It has no other users and no server of its own.

Google user data it accesses

With the channel owner's consent, given on Google's sign-in screen, the tool uses the YouTube Data API and the YouTube Analytics API to:

  • upload videos and thumbnails to the owner's channel and set their titles, descriptions, tags and privacy;
  • read and update the metadata of the channel's own videos and playlists;
  • read statistics of the channel's own videos (views, likes, analytics reports).

It does not read any other Google data and does not access other people's channels or accounts.

How the data is used, stored and shared

  • The sign-in token is stored only on the owner's computer, in the macOS Keychain. It is never sent anywhere except to Google.
  • Video statistics are kept in a local database on the same computer, to plan the channel's next videos.
  • No data is sold, shared with third parties, or used for advertising.

The tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time on the Google Account third-party access page. Deleting the token from the macOS Keychain and the local database removes all data the tool keeps.
